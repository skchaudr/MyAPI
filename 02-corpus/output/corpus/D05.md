# D05 — Empty allow-list → operator / default executor

> Empty allow-list → operator/default executor

## Decision

When a node has not constrained executors, the operator’s explicit pick wins. `auto` resolves to configured `default_executor`.

## Rationale

Operator authority is the point of the allow-list; empty list must not strand dispatch.
