## Question

(Plain English.) When the system doesn’t know, or only has weak/old/conflicting sources, what should it do instead of sounding sure?

## Answer

Already fixed by the north star — not a new product debate.

- Prefer “no evidence / weak evidence” over confident wrong answers (the Graphify failure mode you already named).
- Responses must be grounded in paths/sources when they claim something; if they can’t, say so.
- Don’t invent project truth. Agents should be able to tell “we know this” from “we don’t.”
- Exact JSON field names are an implementation detail at build time, not a separate strategy ticket.
